# Student Performance Prediction — Week 6 Final Assignment

## Files
- `Student_Performance_Prediction.ipynb` — complete notebook with cleaning, EDA, training, prediction, and evaluation.
- `student_performance_dataset.csv` — bundled synthetic sample dataset; not real student records.
- `Student_Performance_Prediction_Report.pdf` — report with the assignment sections and computed illustrative metrics.

## Run
1. Install Python 3.10+.
2. Install dependencies: `pip install pandas numpy matplotlib seaborn scikit-learn jupyter`
3. Place the notebook and CSV in the same folder.
4. Run `jupyter notebook` and execute all cells from top to bottom.

The notebook uses the included CSV so it runs offline. The report's metrics are computed from this synthetic sample and must not be described as results on real student records. The notebook includes a link and guidance for an optional UCI Student Performance real-data extension.
